# DigiGarment Homepage

This is the frontend coding version of the DigiGarment homepage mockup.

## Files
- index.html
- css/styles.css
- js/data-modules.js
- js/supabase.js
- js/main.js

## Logo
Place the finalized DigiGarment `logo.png` in the project root:

D:\WEBSITE\logo.png

## Run
Open with a local HTTP server, for example VS Code Live Server.

Supabase is intentionally optional. The PostgreSQL DATABASE_URL must never be placed in frontend JavaScript.
