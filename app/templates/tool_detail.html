    Formula & Methodology

    The standard formula used to compute Standard Allowed Minutes (SAM) is:

    Swatch Surface Area 100.0 cm²

    Formula & Weight Classification

    The standard formula used to compute fabric Grams per Square Meter (GSM) is:

    GSM = (Weight in grams * 10,000) / Swatch Area in cm²

    For standard circular cutters with a diameter of 11.28cm, the area is exactly 100 cm² (0.01 m²), simplifying the calculation to:

    GSM = Swatch Weight in grams * 100

    Calculated Output

    Estimated Thread Required 0.00 m

    Raw Thread (No Wastage) 0.00 m

    How this calculation works

    Estimated Thread Consumption — calculated based on the selected stitch class and the stated assumptions. Thread length consumed is proportional to seam length and loop structure, plus wastage:

    Thread Consumed = Seam Length * Stitch Multiplier * (1 + Wastage % / 100)

    Important assumptions

    • Stitch Class: Standard garment loops (301 lock, 401 chain, 504 overlock).
    • Stitch Multiplier: Lockstitch uses 2.5x; Chainstitch uses 4.5x; 3-Thread Overlock uses 14.0x seam length.
    • Stitch Density: Assumes a standard sewing density of 10-12 Stitches Per Inch (SPI).
    • Fabric Thickness: Average knit/woven assembly of approximately 1.5mm compressed seam thickness.
    • Wastage: Default 15% allowance factors in sewing ends, thread breaks, and machine styling scrap.

    Example calculation

    For a 1.2-meter seam using a 3-Thread Overlock (Stitch 504) with a 15% wastage allowance:
    1.2m * 14.0 (multiplier) * 1.15 (wastage) = 19.32 meters of estimated thread.

    Disclaimer: Actual thread consumption may vary depending on stitch density, machine settings, seam construction, fabric type, thread type, and garment construction.

    Calculated Output

    Estimated Fabric Weight 0.0 g
    Weight per Dozen (12 pcs) 0.00 kg
    Raw Weight (No Wastage) 0.0 g

    How this calculation works

    Estimated Fabric Consumption — Basic Knit T-Shirt/Polo Model. Calculates front and back body panel surface areas using flat width and length parameters, factoring in seam allowances and fabric density:

    Garment Weight (g) = [ ((Body Length + Hem Allow) * (Chest Width + Seam Allow) * 2 * GSM) / 10,000 ] * (1 + Wastage % / 100)

    Important assumptions

    • Garment Style: Designed strictly for standard rectangular-cut knit structures (basic short-sleeve crewneck or Polo).
    • Chest Width Flat: Measured flat pit-to-pit. A seam allowance factor (+2cm total flat margin) is added to cover joining stitches.
    • Body Length: Shoulder high point to bottom edge. A hem allowance factor (+4cm total margin) is added for bottom folding.
    • Fabric GSM: Grams per Square Meter. Assumes density is uniform across the fabric roll.
    • Wastage: Standard 10% allowance accommodates cutting margins, panel faults, and roll ends.
    • Exclusions: This model is NOT intended as a universal formula for: raglan garments, trousers, leggings, complex panel garments, highly shaped garments, or garments requiring marker-based consumption.

    Example calculation

    For a T-shirt with Body Length = 70cm (+4cm), Chest Width = 50cm (+2cm), GSM = 180, and Wastage = 10%:
    Weight = [ (74 * 52 * 2 * 180) / 10000 ] * 1.10 = 138.52g * 1.10 = 152.4 grams/garment (1.83 kg per dozen).

    Disclaimer: Actual production consumption may vary based on pattern shape, marker efficiency, size ratio, fabric width, shrinkage, and garment construction.

    Calculated Output

    How this calculation works

    Estimates total FOB export price by summing manufacturing layers (fabric, CM, trim, accessories, logistics) and applying profit markups:

    FOB Cost = (Fabric + CM + Trims + Packing + Logistics) * (1 + Profit Markup % / 100)

    Important assumptions

    • FOB Pricing: Free On Board port of origin pricing. Excludes marine shipping freight charges, destination port tariffs, and custom duties.
    • Profit Margin: Percent markup. A 15% markup multiplies total factory cost by 1.15.
    • Unit Currency: Calculations are currency-agnostic (commonly quoted in USD).

    Example calculation

    For costs of Fabric = $1.50, CM = $0.50, Trims = $0.20, Accessories = $0.15, Logistics = $0.10, and Profit Markup = 15%:
    Total cost = $2.45. FOB price = $2.45 * 1.15 = $2.82 per garment.

    Disclaimer: This estimate represents the FOB cost at port of origin and does not include international shipping tariffs, freight forwarder handling fees, or marine insurance.

    Calculator Inputs

    Price of cotton/polyester raw yarn per kg.
    Circular knitting mill processing charges per kg.

    Yarn lint loss, dyeing shrinkage, and fabric roll edge trimming loss.
    ⚖️

    Enter details on the left and click "Calculate Fabric Cost" to view results.

    Calculated Output

    Estimated Finished Fabric Cost per kg $0.00
    Raw Sum (Yarn + Knit + Dye) $0.00
    Wastage Loss Value / kg $0.00

    How this calculation works

    Estimates total finished fabric cost per kg by summing material costs and dividing by yield margin:

    Fabric Cost/kg = (Yarn Cost + Knitting Rate + Dyeing Rate) / (1 - Wastage % / 100)

    Important assumptions

    • Fabric type: Knitting mill parameters. Excludes woven sizing and weaving loom setup fees.
    • Process wastage: Includes yarn lint loss, knitting faults, dyeing shrinkage, and edge trim waste.

    Example calculation

    For Yarn = $3.20/kg, Knitting = $0.30/kg, Dyeing = $1.20/kg, and process wastage = 5%:
    Raw sum = $4.70/kg. Finished cost = $4.70 / (1 - 0.05) = $4.70 / 0.95 = $4.95 per kg.

    Disclaimer: Estimates finished cost per kg at mill door. Excludes bulk shipping from dyehouse, yarn testing laboratory fees, and color-matching surcharge costs.

    How this calculation works

    Calculates Cut & Make (CM) cost per piece by dividing the total daily operating cost of a sewing line by its expected output:

    CM Cost/Piece = (Daily Overhead + (Operators Count * Daily Operator Wage)) / (Target Output * Efficiency % / 100)

    Important assumptions

    • Line overhead: Daily running cost of sewing machine depreciation, supervision, line checking, and utilities.
    • Distribution: Assumes overhead and target allocations are distributed uniformly across the active machines in the line.

    Example calculation

    For Operators = 20, Daily Wage = $10, Daily Overhead = $150, Target Output = 2000 pcs, and Line Efficiency = 80%:
    Daily Cost = $350. Expected output = 1600 pcs. CM cost = $350 / 1600 = $0.22 per piece.

    Disclaimer: CM calculation is based on distributed line overhead allocations. Actual plant-wide CM cost per garment may differ based on downtime, sampling rounds, pattern grading, and machine layouts.
